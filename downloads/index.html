03 / NEED TO KNOW

QUESTIONS FRÉQUENTES

Les jeux proposés sont-ils gratuits ?

Oui, notre sélection de départ présente des jeux gratuits. Vérifie toujours les conditions affichées sur le site officiel avant de télécharger.

Est-ce que TOV4R héberge des installateurs ?

Non. Le bouton de téléchargement ouvre le site officiel du développeur. Nous n'hébergeons pas de copies, d'exécutables ni de versions modifiées.

Comment ajouter un jeu à la collection ?

Le catalogue peut être enrichi depuis son fichier games.js. Il faut un lien officiel fonctionnel et une autorisation appropriée pour tout fichier que l'on veut héberger.

Pourquoi une image ne charge-t-elle pas ?

Les captures proviennent de sources externes. Si une source est temporairement indisponible, le site affiche une couverture de remplacement avec le titre du jeu.
