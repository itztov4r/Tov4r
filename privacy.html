Informations & transparence

Confidentialité

TOV4R est un portfolio gaming sans compte visiteur ni statistiques inventées sur ses pages publiques.

Mesure d'audience

Le site utilise Umami Analytics pour mesurer sa fréquentation. Le script de mesure n'est pas chargé si le navigateur annonce Do Not Track ou Global Privacy Control. Les chiffres de fréquentation réels sont consultables uniquement par le propriétaire sur Umami. Le fournisseur peut traiter des données techniques de visite.

Images, vidéos et services tiers

Le site contient des images d'Unsplash, des vidéos Medal et des liens vers Steam, Discord et d'autres plateformes. Le chargement de médias distants ou la consultation de ces liens peut transmettre des informations techniques (notamment l'adresse IP) aux plateformes correspondantes.

Stockage local

Les choix d'apparence, démonstrations Crosshair et brouillons facultatifs de Clips ou Progress sont enregistrés dans le navigateur utilisé. Ce stockage n'est pas un compte public ni une base de données synchronisée. Il peut être effacé depuis les paramètres du navigateur.

Catalogue

TOV4R DOWNLOAD est un catalogue de jeux gratuits avec liens vers les pages officielles, pas un hébergement de fichiers d'installation.
