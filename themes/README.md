# TOV4R Death Note — BetterDiscord Theme

A **notebook-inspired**, dark crimson/ink-black Discord theme by TOV4R. This is an **unofficial fan-inspired** design, not affiliated with Death Note, Discord, or BetterDiscord.

## Preview / concept
- Dark ink panels with crimson notebook-margin highlights.
- Ruled-paper texture in the chat area.
- Clear unread states, readable text and accessible dialogs.
- Reduced-motion and high-contrast fallbacks.
- Optional wallpaper configuration.

## Install
1. Download [TOV4R-DeathNote.theme.css](themes/TOV4R-DeathNote.theme.css) as a file.
2. In Discord with BetterDiscord installed, open **Settings → BetterDiscord → Themes → Open Themes Folder**.
3. Place the `.theme.css` file there and enable it.
4. Set **Appearance → Dark** for the intended palette.

## Optional wallpaper
Edit `--tov4r-dn-wallpaper: none;` near the start of the theme, changing `none` to a CSS `url("...")` pointing to artwork you own or are permitted to use. No third-party anime image is distributed by this public repository.

## Status
- Public GitHub source for installation and experimentation.
- **Not submitted to the official BetterDiscord theme catalog.**
- Generated with AI assistance; **BetterDiscord's publishing guidelines require the submitted theme codebase to be primarily written by the submitting developer**, and simple recolors/background themes are insufficient for approval.
- Discord class names change over time; visual QA in the current desktop client is still required.
