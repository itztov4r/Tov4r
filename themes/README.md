# TOV4R STUDIO — Theme installation guide

## Vencord desktop
1. Open **Settings → Vencord → Themes**.
2. Use the Themes folder / local theme loader to add the downloaded `.theme.css` file.
3. Enable the theme and restart Discord if the interface doesn't refresh.
4. Disable other theme files when troubleshooting conflicting CSS.

## BetterDiscord desktop
1. Install the client mod from the official project website after considering Discord's policies.
2. Open **Settings → BetterDiscord → Themes → Open Themes Folder**.
3. Place the downloaded CSS file in that folder and enable it.

## Wallpaper and personal art
This public catalog does **not** distribute the original Death Note anime wallpaper. Only add images you are permitted to use; do not commit third-party artwork without the necessary permissions.

## Compatibility
Themes affect visual styling, not messages, account credentials or server permissions. Discord updates can break selectors. If a theme causes bad contrast or hidden controls, disable it in your client settings. Use the latest tested version when available.

## Release status
This repository is an **independent** project. No theme here is asserted to have received BetterDiscord or Vencord directory approval.
